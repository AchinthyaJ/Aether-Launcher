Skyrim Set 2
============

Author: ru5tyshark

Notes:
⚪ Skyrim by ru5tyshark ⚪ Updated again!!!! New and improved, don't wait because there's now more! Comes in a handy multisized package for those of you who requested it + extras! I did say if enough people asked for it I would look into it, so here they are. 64, 48, 32 and 24 pixel sizes (I had to breakout my magnifier to see the 24 pixel size lol). Added a new hand link alternative and a few more cursors that were missing. I didn't find any howtos on making them multisized anywhere (probably didn't look hard enough hah) so I just made a guess + trial & error but it seems to work ok on my mint & manjaro distros at that time, have now moved to EndeavourOS so YMMV. Good luck and as always, caveat emptor! ('-' )

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Skyrim Set 2' from the Scheme dropdown
